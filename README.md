**KNOCK** (Kali Network Offensive Comprehensive Kit) is a powerful wrapper around `nmap` that uses `masscan` to dramatically speed up scans by first discovering open ports, then running `nmap` only on those ports – **all without losing any nmap functionality**.

## ✨ Features

- **Full nmap compatibility** – every flag works.
- **AI‑accelerated mode** (`--ai`) – masscan + nmap.
- **Caching** – re‑scan within 5 min uses cached ports.
- **Localhost optimisation** – faster on 127.0.0.1.
- **Coloured output**.
- **Parallelism** – auto‑CPU cores.
- **Open‑source** – MIT license.
