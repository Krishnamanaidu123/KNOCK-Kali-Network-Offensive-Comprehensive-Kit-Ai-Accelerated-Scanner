Installation

One-liner (Linux/macOS)

Review any install script before piping it into a shell — here's the direct source so you can check it first.

curl -sSL https://raw.githubusercontent.com/your-username/knock/main/install.sh -o install.sh
less install.sh        # review it
bash install.sh

Manual

git clone https://github.com/your-username/knock.git
cd knock
sudo cp knock.sh /usr/local/bin/knock
sudo chmod +x /usr/local/bin/knock

Dependencies: nmap, and masscan (optional, but recommended for the speed boost).

sudo apt update && sudo apt install nmap masscan -y

Quick usage

Standard nmap

knock -sS -sV -O 192.168.1.1

AI-accelerated

sudo knock --ai -sV -O 10.0.2.11

Ping sweep

knock --ai -sn 10.0.0.0/24

Custom masscan rate

sudo knock --ai --masscan-rate 10000 -A example.com

KNOCK only scans hosts and ranges you own or have explicit written authorization to test.
